# Code of Conduct

## Contributor Covenant

本项目遵循 Contributor Covenant 2.0。参与者应保持尊重、包容和建设性，
不得进行骚扰、歧视、威胁或恶意攻击。

This project follows the Contributor Covenant 2.0. Participants are expected
to be respectful, inclusive, and constructive. Harassment, discrimination,
threats, and abusive behavior are not accepted.

如需报告行为问题，请通过项目的
[Issues](https://github.com/thisisac/WHUerMap/issues) 页面联系维护者。

Please report conduct concerns through the project
[issue tracker](https://github.com/thisisac/WHUerMap/issues).
