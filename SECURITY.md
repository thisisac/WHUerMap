# Security Policy

## Supported Versions

WHUerMap is an educational open-source project. Security fixes are considered
for the latest `main` branch and the newest published release.

## Reporting a Vulnerability

请不要在公开 issue 中发布密码、服务端凭据、签名密钥、真实位置记录或可
直接利用的漏洞细节。仓库创建后，请使用 GitHub 的
[Private vulnerability reporting](https://github.com/thisisac/WHUerMap/security/advisories/new)
提交安全问题；如果该功能不可用，再通过项目
[Issues](https://github.com/thisisac/WHUerMap/issues) 请求私下联系。

Do not disclose credentials, signing keys, real location traces, or exploitable
details in a public issue. After the repository is created, use GitHub Private
Vulnerability Reporting, or request a private contact through the issue tracker.
